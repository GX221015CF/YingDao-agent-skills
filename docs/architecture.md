# 架构与两条用户路径

## 五类资产

|类别|内容|使用条件|
|---|---|---|
|Skill 方法|任务路由、需求与取舍、实施准备、停止与验收|由宿主Agent读取并按任务使用|
|可复用离线工具|候选校验、反馈解析、材料摘要和映射|本仓库标准库Python入口|
|固定案例执行器|历史案例中使用的任务适配|在来源项目按接口版本维护|
|历史现场结果|真实案例摘要与证据记录|按案例日期、环境与样本解释|
|当前复现能力|合成示例、单元测试与CLI|按README命令在本机运行|

## 路径 A：需求到搭建

用户目标 → Skill 澄清输入输出、业务键与异常 → 设计 VisualFlow/CodeFlow 分工和依赖 → 当前版本接口核验 → 候选配置 → 适用执行器和当前授权 → 写入及完整回读 → 获准运行与结果验收。

本版可直接运行的是中间的“合成候选局部校验”和末端的“规范反馈解析”。前后真实现场步骤是方法说明，没有提供现场客户端。六节点构造器也不是 ShadowBot 解释器。

## 路径 B：已有应用到复用

明确来源和范围 → 整理流程/代码/参数/变量/元素/资源/依赖 → 建立材料与引用映射 → 验证字节和缺件 → 准备交付或重建候选 → 当前版本正常接入 → 目标端验收。

应用迁移Skill覆盖这条完整工作流，并提供原项目已有迁移工具的选路与适配说明。图像、元素、流程及依赖分别核验。本版可运行示例只复现清单、资源和映射检查，组件中的流程ID为输入声明。现场接入器保留在来源项目，按当前版本、材料和授权检查。

## 四种迁移产物必须区分

- **自有存档容器**：工具自定义的文件集合和清单，可做离线完整性检查。历史工具的自有格式不是影刀原生包；本版没有打包器。
- **离线恢复目录**：把存档还原到新本地目录，只证明文件恢复；不是原生工作区导入。
- **重建候选**：字段、流程、资源和新 ID 槽位的计划；不是可直接执行的 MCP 请求。
- **影刀原生接入**：需当前产品支持的接口、身份与权限、资源及字段回读、必要验证。前三者都不能代替它。

## 数据与执行边界

只保留标准库纯函数，无进程、网络、SDK、浏览器或 Studio 导入。所有输入为 JSON/本地文件，不执行配置中的表达式和代码。CLI 默认资源定位来自入口文件；资源路径限制在显式根目录内，禁止链接和路径碰撞。

示例输出写标准输出，测试临时材料写 work 并清理。work 和 .local 不公开；公开候选通过 public-files.json 显式列出，不靠 .gitignore 作为唯一边界。

摘要证明字节自洽，不认证来源；输入 complete 声明不认证完整采集。校验器支持的 Schema 子集继承原项目，不是完整 JSON Schema 引擎。
