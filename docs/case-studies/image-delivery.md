# 脱敏案例：应用迁移中的图像材料交付

证据性质：历史现场及交付摘要；本轮没有读取、复制真实图片或重跑 SDK。内部来源编号 SRC-10、SRC-11。

## 问题

应用迁移涉及本地图像、远程语义参考图和原图标。文件存在、字段正确和业务可用属于不同证据，不能通过单一“成功”标记验收。

## 处理

- 按准确来源清单建立资源、字段和交付文件映射。
- 四项本地图像保留原尺寸与参数，在独立环境校准及真实 SDK 匹配。
- 对通用二进制 MIME 使用有界正文和真实格式校验，取得 17 份语义参考图。
- 18 处引用完整映射，保留两处共享同一资源的关系；原引用及关闭状态保持。
- 最终按用户确认的“应用可用、约定材料完整”验收；两份原图标仍缺，用户明确接受本次排除，不记成已取得。

## 历史结果

4 项真实图像：37,346 个 RGB 像素无差异；4 次 SDK 匹配为 True，无 UIAError。独立结果不冒充真实业务页面定位。

补充交付 21 份原字节图像，共 33,742,227 字节，包含 4 份本地图像和 17 份参考图，附 18 处映射。应用功能由用户实际使用确认。缺少最初捕获资源摘要的版本限制单列，没有把本次下载证明成历史版本认证。
