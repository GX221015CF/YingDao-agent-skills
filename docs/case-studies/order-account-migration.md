# 订单核查应用的同机跨账号迁移

本次在同一台 Windows 电脑上，将已验收的订单核查应用从影刀 A 账号迁到 B 账号。目标账号正常保存、关闭重开及结果验收均通过。两次正式运行中，第一次在浏览器绑定阶段因多用户环境提示结束，第二次完成核查。源端保持原态，源流程没有重跑。

## 使用的方法与实现

使用全局 `yingdao-app-migration` 1.0.0 的迁移工作流、工具与证据、本地工具索引、图像材料和分层验收方法，结合 `yingdao-rpa-copilot` 的正常客户端核验及受控运行方法。

优先检查已有迁移实现，复用完整元素采集器、原生工程桥接器、纯工程格式编解码函数、正常客户端及原有独立结果验收逻辑。实际执行代码属于本地历史工具和任务适配，仓库 Skill 提供选路及验收方法。当前案例文件没有捆绑现场执行器或历史 codec。

当前工具 Schema 缺少官方导出、应用创建及完整元素读取能力，用户也未看到导出、分享或复制入口。本次通过准确源工程取得完整材料，使用正常接口与原生工程侧文件相结合的实验接入方式。自有 `.ydnative` 存档需配套接入器使用。

## 来源采集及最小适配

通过已有准确工程根记录和当前正常 app_id 定向定位源工程，核对磁盘 UUID、名称及当前正常配置。两遍定向读取一致，保存了 16 份来源原字节，包括流程定义、代码、项目说明与支撑文件、完整元素库、空图像库和五个本地图像文件。

|组成|来源与目标结果|
|---|---|
|流程|空 main、21 节点采样流程、28 节点订单核查流程及一个计算 CodeFlow，四个流程均保留|
|参数与调用|四个 In/Out 参数、四处静态子流程调用、原输出槽与变量关系保留|
|完整元素|四个原生元素及分组身份保留，完整 XML 与来源原字节一致|
|本地图像|四张已有普通元素截图和一个分组图标，目标字节及准确绑定一致|
|语义参考图|四处共享一份资源，原字节另存，原引用及 disabled 状态保留|
|依赖与全局|额外声明依赖、共享依赖、全局变量及正常资源清单均为空，未安装依赖|

旧接入器中的固定源样本和 `process5` 空流程证明替换为本次准确来源 manifest 与已有空 main 定义。保持成员摘要、路径安全、空目标、空库、支撑模板、相对导入及引用闭合检查。创建流程时保留来源显示名，并补上旧接入器未覆盖的准确分组图标复制。codec 仅提取已审查的两个纯编解码函数，使用既有归档常量，没有执行旧固定恢复入口或目标业务代码。

四份模型编解码往返、49 节点身份、四调用闭合、支撑模板及篡改成员和错误映射拒绝等十项针对性离线检查通过。源端原有 15 项业务逻辑测试沿用历史有效结果。

## 接入过程中的实际差异

用户正常切换账号并创建 B 端空应用，Agent 通过正常接口确认准确身份、空 main 和空库，备份涉及文件的前态。随后一次接入创建三个非主流程、写入代码与参数、恢复九个原生侧文件，正常重载一次并显式保存两次。

接入器在完成上述动作后，因严格 M0 摘要比较发现四个 URL 为空而停止。保留首次回执和实际残留，没有重发接入。定向核查表明四份完整元素 XML 与来源字节相同，XPath 也全部一致，源 XML 中没有独立 URL 属性。B 端 URL 摘要一致性仍列为差异，完整定义、业务字段和实际使用结果分别核验。没有补造 URL 字段或重新捕获元素。

仅调整正式核查中的输入副本路径、全新输出路径及输出防覆盖检查。业务规则、金额口径、输入与独立预期均保持来源值。122 项字段检查确认仅计划路径发生变化。

## 保存、归属与分工

B 端两次运行自动保存了本任务已知路径调整。完成后正常接口确认 clean，用户在 B 账号下正常关闭编辑器、从应用列表重新打开目标，Agent 再核对同一应用身份、流程目录、完整核查字段、代码及元素回读均保持一致。目标保留由产品正常生成的账号归属信息，源端 16 份已采集原始文件摘要均未变化。

用户承担正常账号切换、创建空应用、现场反馈与关闭重开。Agent 完成工具适用性审查、完整材料采集、最小适配、目标前态保护、接入、配置回读、路径调整、受控运行和结果验收。四个元素均沿用源定义，本批重新捕获零次。

本次证明该订单案例在同机两个影刀账号、影刀 6.3.39 和现有 Edge 集成环境中的结构、保存、实际使用及业务结果。分页遍历、自然多匹配、其他设备和其他版本仍按实际未覆盖范围保留。B 端四项正常元素 URL 摘要为空的差异继续记录。

语义功能保持关闭，参考图只作为可追溯材料与绑定保存。本批没有 AI、Agent 采屏、Computer Use、凭据或账号缓存读取、依赖安装、订单修改、源端重跑或 GitHub 推送。运行时浏览器网络请求总数没有采集。

另机接收需保留正常应用迁移载体、原生元素与图像、冻结台账、独立预期和验证器，并映射新的输入输出位置。当前实验接入器依赖本地已审查工具、codec 及归档常量，尚未整理成自包含的跨设备工具包。目标电脑的影刀与账号权限、Edge 集成、Python 环境及 Agent 可达性需另行核验。
