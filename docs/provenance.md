# 来源与公开适配

公开候选由明确的自编代码、Skill 文档及历史报告选材。只读检查来源后提取必要部分，没有复制整个项目、商业程序集、软件提取代码或真实业务材料。

|来源编号|公开产物|适配方式|
|---|---|---|
|SRC-01|tools/branch_candidate.py|六节点纯函数构造器原文复用；不带现场 probe|
|SRC-02|tools/portable_validation.py|提取纯候选、JSON 与反馈校验；删除客户端加载和 CLI；增加 pending 字面状态支持|
|SRC-03|tools/schema_subset.py|只提取 Schema 常量、错误类型与纯校验函数；无进程/端点/传输和缓存代码|
|SRC-04|tools/migration_paths.py|只提取 SHA-256、安全相对路径及碰撞检查|
|SRC-05|公开 yingdao-rpa-copilot Skill|精简、重组引用，删去私人路径和固定案例执行入口；现场方法保留，执行能力单列|
|SRC-06、SRC-07|公开 yingdao-image-migration Skill|保留名称与图像范围；改写说明为中文，补充离线能力与解码证据边界|
|SRC-08、SRC-09|订单脱敏复盘|只保留问题、方法、数量和结果层级|
|SRC-10、SRC-11|图像交付脱敏复盘|只保留原字节/映射/SDK及范围决定摘要|

完整源文件位置、修改前摘要和目标提取对应存于维护者本地 .local，未列入公开文件清单。公开编号不提供私人来源反向路径，也不需要来源文件即可运行。

tools/automation.py、tools/migration.py、CLI、测试和合成材料是为了本版最小示例新增的适配，不声称是原项目中已有的通用执行器。保留原项目实现和已安装 Skill，没有同步覆盖或自动安装。

经维护者认可当前候选并批准许可，文件集中确认有权许可的自编内容采用根目录标准 MIT。上述来源编号、适配关系和不纳入内容继续保留；MIT 不重新许可商业产品、第三方权利或未提交的业务材料。完整适用范围见[许可说明](licensing.md)。

## 纳入与排除

纳入：方法文档、必要纯函数、合成 JSON/SVG、离线测试、最小脱敏案例。
排除：真实图片、名单、证书、完整订单日志、原始配置、历史应用 ID/端口/PID、一次性批准或操作回执、客户端传输和现场执行器、缓存及依赖环境、商业软件及未确认可再分发内容。
