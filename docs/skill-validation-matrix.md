# 双 Skill 真实案例能力验证矩阵

本矩阵只整理仓库已保存的 Skill 说明、能力表和脱敏案例。等级表示现有真实案例对该项能力的证据强度，不表示能力对任意应用或环境普遍成立。合成离线测试、Skill 文本覆盖和历史源码存在均不单独作为真实使用证明。

等级含义：

- **有真实案例支持**：有实际影刀现场操作或结果证据支持该项具体行为；结论仍限于所列样本。
- **部分支持**：有相关现场证据，但关键部分由人工、任务专用适配或外部工具完成，或重要场景尚未覆盖。
- **尚无证据**：现有脱敏案例没有证明该项能力已在现场完成。

## 结论

两个 Skill 都已有足以展示实际使用方式的真实案例：自动化 Skill 有从需求拆解、流程搭建、元素修正、配置回读到运行结果验收的源端案例；迁移 Skill 有同机跨账号完整结构接入、保存重开和业务结果验收案例，并有图像材料映射证据。它们适合作为有边界的案例展示，不足以支持“通用自动搭建”或“跨设备通用迁移”的承诺。

仍重要但未验证的能力包括：RPA Skill 在任意应用、不同客户端版本和无人值守环境中的通用执行；订单查询中的自然分页、多条精确候选及会话失效现场处理；迁移 Skill 在其他设备或版本上的复现、官方原生导入/导出，以及不依赖本地历史工具/codec的自包含迁移执行。已有案例的人工捕获、实验接入器依赖和摘要差异应与结果一起展示。
