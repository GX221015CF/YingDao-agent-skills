# 图像材料专项

图像属于应用组成的一部分。按完整元素定义、图像库、资源及准确引用识别实际需要的材料。没有独立图像资源时记录依据，普通资源列表为空仍需核对元素内部引用。

## 分类及映射

|类别|重点|
|---|---|
|普通元素截图|完整selector中的引用、编码/相对路径、工程根、实际原字节。普通预览主要消费该字段|
|本地图像/图像库|库索引、匹配参数、原尺寸、图像ID与流程字段引用|
|语义参考图|semantic.image、rectangle、desc、status及多字段共享同一资源的关系|
|分组/元素图标|准确group或元素字段、唯一来源路径、原件及缺件决定|

每项记录来源证据、源字段、文件/资源编号、字节数、SHA-256、目标位置和每处绑定。已有解码、尺寸及透明度证据有效时复用，新增解码/SDK实验由本批实际需要决定。原字节副本保持内容，转码或重捕获须说明原因与影响。

## 获取与缺件

来源明确的本地文件或正式导出按清单定向读取。远程图片仅按准确来源引用，在获准范围内限定次数、大小和超时，不猜测地址、搬用凭据或盲目跟随重定向。HTTP200还需检查正文。application/octet-stream可通过实际格式/解码验证有效，HTML/登录页或错误响应保留真实失败原因。

原URL和查询参数以来源记录编号关联，避免出现在聊天、公开文件或文件名中。共享资源去重保存，保留每处引用。缺少最初捕获摘要时说明版本证据限制，是否影响验收按用户范围判断。

图标只按准确字段及唯一来源追索。已确认缺失的路径复用结果，禁止扫描找相似图、默认替代或补画冒充原件。明确记录缺少哪个对象、来源证据和最小补件动作。用户接受排除时保存决定，原件取得状态仍保持真实。

## 绑定、加载与验收

保留源功能开关，原态disabled按迁移一致性保存。语义图片材料及磁盘引用核对可以独立完成。若用户验收只含应用可用与材料完整，未开展AI测试按范围记录。

普通selector.screenshot预览不能推导semantic.image消费者加载。图片字节、字段保存、账号访问、实际加载、语义执行和业务结果分别记证据。正常资源登记需要与语义绑定合同对应，不能仅凭普通资源添加宣称接入。

需要更高层验证时，说明产品准确入口、会读取或发送的数据、新画面采集、账号权益/费用、字段及dirty影响、取消/恢复方法、成功与停止标准。未知影响继续补准确合同，不用笼统批准替代。

图像交付目录保存原字节、清单及资源→字段→文件映射，并回读摘要。已有原应用工程和迁移包保持可追溯。SDK合成实验、真实材料独立匹配、真实业务页面定位各有不同证据范围。
