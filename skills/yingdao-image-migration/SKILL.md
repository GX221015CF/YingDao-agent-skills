# 影刀图像迁移（公开候选）

本 Skill 承载图像迁移方法与模板。应用迁移还涉及流程、代码、参数、变量和依赖；本仓库的合成清单核验只是其中一环。

## 工作流

1. 读取项目最新有效状态和报告，复用已完成采集、验证与交付。先确认用户验收范围，不默认要求开启原来关闭的功能。
2. 真实目标修改前核验应用名、app_id、账号可识别身份、加载状态、clean/dirty 和准确前态。该文档不提供现场写入器。
3. 分开记录本地图像、语义参考图、原图标；逐项连接来源、原字段、文件长度与 SHA-256、目标或交付位置。共享资源只保存一份，但保留每处绑定。
4. 保留原字节。已有合格解码证据按需复用；缺少证据时才在获准范围内验证格式、尺寸与透明度。清单的摘要通过不能冒充解码通过。
5. 原图标只能从明确来源定向读取；缺件保留，不扫描找替代品、不猜路径、不补画、不用默认图标冒充。是否排除由用户明确决定。
6. 遇到远程材料时，仅按已批准准确引用获取，限定次数、超时和大小，不猜 URL、不搬用凭据、不盲目重定向。通用二进制 MIME 需结合正文识别；HTTP200 不单独作为有效性证明。
7. 文件写入使用独立版本目录并回读摘要；应用字段变更需要正常合同、准确旧/新映射和恢复依据。未知响应先核查，不重发。
8. 使用[分层验收](references/acceptance-layers.md)，按[报告模板](references/report-template.md)交付。任务在用户约定范围达到后关闭，保留范围外未知。

先体验[合成迁移清单示例](../../examples/migration/README.md)：它只核验本地字节与映射，不解码、不下载、不上传、不调用 SDK 或原生导入。公开版与原安装版关系见[来源说明](../../docs/provenance.md)。
