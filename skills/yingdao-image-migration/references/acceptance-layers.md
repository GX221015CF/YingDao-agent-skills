# 分层验收

逐层记录 pass、fail、unknown 或 not_in_scope，并附依据。每层分别取证，不需要为了低层材料交付自动执行所有高层实验。

|层级|需要的证据|
|---|---|
|材料存在|清单所指准确对象存在|
|内容有效|格式校验与解码、尺寸、透明度；字节与 SHA-256 单列|
|来源一致|唯一来源记录；历史版本一致还需历史摘要或版本证据|
|字段绑定|每处源字段到资源/文件的准确映射，保留共享关系|
|目标保存|目标实际配置完整回读及保存状态|
|账号访问|目标账号通过正常路径访问资源的结果|
|消费者加载|当前消费者实际读取了对应图像的明确证据|
|语义执行|正常语义操作的实际结果及影响|
|业务成功|实际业务结果|
|全面逆向|更广的软件行为与实现证据，不由样本迁移推导|

本仓库清单工具只检查声明结构、映射和字节完整性。其 component complete 为提供者声明，不是完整采集认证。它不解码图片，也不证明原图身份。

普通截图、预览、HTTP200、disabled 状态和配置存在都不能替代加载或业务成功。独立测试应用的结果不能冒充真实业务页面定位。

真正缺件不能静默移出范围。用户可以明确接受例外；保留缺件事实和决定。任务按约定层级完成时收尾，范围外未验证不自动阻止关闭。
