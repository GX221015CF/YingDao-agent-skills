# 图像迁移报告模板

## 范围与目标
记录实际应用身份、来源证据、当前阶段、用户验收层级、允许动作和明确排除项。来源身份未知时直说，不用历史应用 ID 代替现场事实。

## 材料清单
|编号|类别|来源记录编号|原字段|交付相对路径|字节|SHA-256|格式/尺寸/透明度证据|状态|
|---|---|---|---|---|---|---|---|---|

## 字段映射
每处字段列出资源编号及文件；共享资源去重但绑定不省略。敏感 URL 使用摘要或来源位置定位，不在公开报告展开。

## 缺件
记录准确缺少对象、已知来源、原因、最小补件动作以及是否需要新增权限。原图标例外必须有用户明确决定。

## 操作与验证
分别记录读取、获取、解码、写入、回读、保存、重载、运行、采屏和 AI 的实际次数及未知项。区分本次执行和历史证据。

## 结论与关闭
按验收层级逐项写通过、失败、未知和范围外；给出交付文件集、限制与最多三个下一步。不要将材料齐全、字段绑定、加载及业务成功合为一项。
