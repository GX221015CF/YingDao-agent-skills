# 现场边界

本候选没有进程发现、客户端传输、写入、保存或运行工具。离线示例不带现场授权，不连接已安装影刀。

后续如需接入，先核验当前正常客户端、Schema、账号可识别身份、应用名与 app_id、实际 flow_id、加载/运行/调试状态、弹窗及 clean/dirty。历史端口、PID、应用和案例批准不能复用为当前事实。

在已有授权和实际合同支持范围内推进；结构修改、保存、重载、运行和业务影响分别说明，不重复请求已明确批准的同范围动作。工具可能自动持久化或运行可能自动保存时，先披露相应影响。

保护原应用，优先明确副本；不覆盖无关改动。响应不确定先读状态；部分成功不自动覆盖或回滚。登录、生产提交、发送、付款和删除需要对应业务授权。

没有正式能力时准确说明缺口，不读取凭据或账号缓存，不调用私有桥接。采屏、AI 或其他外部影响需要单独控制。历史案例只作方法参考。
